## 本阶段改动

1. 翻译的评分输入包含整篇原文及各题原句、参考译法和作答。未答题保持为空，分母仍为整组 10 分。
2. 小作文保留原题分项要求，不给未要求的格式额外设扣分条件。
3. 六年大作文的图片使用经原图核实的文字描述，表格和题目要求继续保留在原文中。描述只补充文字模型看不到的画面和数据，不指定唯一立意，也不改写正式题库原文。
4. 只有已核实的本机原图路径和正式 Supabase 原图 URL 使用对应描述。图片未知或年份错配时停止评分，避免无依据批改。
5. 模型结果缺少有效数字分数、缺少评语、越界或被截断时，任务失败并允许重试，不把不完整结果静默记成零分。有效、有评语的零分仍可保存为建议。
6. 记录 API 返回的实际模型名。建议分仍需用户确认，才能成为正式成绩。

涉及文件：`lib/english-subjective-prompt.ts`、`lib/english-subjective-grade.ts`、`lib/server-english-subjective-grade.ts`、`tests/english-subjective-grade.test.mjs`、`package.json`。

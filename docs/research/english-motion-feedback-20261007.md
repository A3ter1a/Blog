# 英语训练动效与点击反馈收尾

主任务：对英语训练入口、题组、题号、选项、作答卡片、答题栏和批改窗口，以及保存/提交/重置/修改操作提供立即可见的反馈。真实入口为 `/tools/english-training`。

Decision: Retain。复用现有 Framer Motion、`uiMotion` 和主题颜色；用 CSS 按压反馈配合状态反馈，补齐缺少的开合动画。只改两份英语训练 TSX 与英语范围内的 CSS，不改题库、评分规则、后台权限或任务模型，不新增依赖。

基线：原页面1194×1160，无横向溢出；题号菜单没有开合动画，页面阶段直接卸载；批改/答题栏使用不同缓动且未完全响应减少动效设置。正式旧训练路径下的AI按钮存在静默不可操作状态。

规格：按钮按压80ms、0.97缩放和1px位移；状态颜色140ms；阶段和浮动卡片180ms；答题栏与批改窗口240ms。沿用标准缓动。移动端独立操作按钮最低44px；减少动效时取消缩放、位移和过渡，保留选中颜色、焦点和操作消息。关闭动画中的内容立即inert，防止误点；关闭中的浮层不拦截后面的操作。

验证画布：2560×1440桌面、390×844移动端。隔离预览端口3031，使用本机训练记录，不保存正式作答。收尾后会更新3020的本机正常服务。

范围内变更：阶段过渡、菜单/卡片/答题栏/批改窗口对称开合、按压和焦点反馈、只读/占用/空重置原因提示、等待按钮文案、Escape及焦点返回、减少动效。

既有后台限制：正常旧训练路径尚未启用主观题AI批改，当前点击会明确说明并保留保存草稿入口；本轮不进行训练数据库迁移。
